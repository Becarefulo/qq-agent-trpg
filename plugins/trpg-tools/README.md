# 跑团工具箱（trpg-tools）

给 **`trpg-gm`（跑团 GM 技能）** 提供底层能力的确定性插件：剧本库、COC 检定、跑团模式开关、剧情进度、人物卡与私密线索、公开名册、物资、情报传播。

> **它自己不注册任何工具。** 工具由 `trpg-gm` 注册，模型决定「什么时候该读剧本 / 掷骰」；这个插件只负责「读出来的内容必须是对的、骰子必须算得准」。
> 所以要跑团，**技能和插件两个都要装**：只装插件 → 模型不知道能跑团；只装技能 → 所有工具回「插件还没装好」。

---

## 安装

1. 安装本插件（跑团工具箱）
2. 安装配套技能：`trpg-gm`（TRPG 跑团 GM）
3. 两个都启用后，能力会自动注册，无需重启

数据全部是本地文件，卸载插件不会自动删数据（数据在 `data/trpg-tools/`）。

## 提供的 20 个能力

| 组 | 能力 | 说明 |
|---|---|---|
| **掷骰** | `trpg.dice-roll` | 支持 `3d6`、`1d100<=60`、`2#1d6`、`1d10*2+3`、括号；单次骰数上限可配 |
| | `trpg.dice-check` | COC 7e 检定：大成功 / 极难 / 困难 / 成功 / 失败 / 大失败，支持奖励骰与惩罚骰（最多 ±10） |
| **跑团状态** | `trpg.gm-get` / `trpg.gm-set` | 每群独立的跑团模式开关（GM 人设只在开启时注入） |
| | `trpg.scene-get` / `trpg.scene-set` | 剧情进度：当前模组 + 第几幕 |
| **人物卡** | `trpg.character-get` / `trpg.character-set` | 读/写自己的卡：力量敏捷体质智力意志魅力幸运、hp/mp/斗气、任意技能 |
| | `trpg.character-background` | 写私密背景故事 |
| | `trpg.character-known` | 已知线索（只自己能看） |
| | `trpg.character-public` | 队伍公开名册（只给公开信息，用于「看队伍」） |
| | `trpg.character-items` | 随身物资，带去重与 12 件上限 |
| **情报传播** | `trpg.intel-record` / `trpg.intel-known` | 记一件「可能被听说的事」，按重要度 × 时间半衰期算出「某地现在可能知道什么、有多可信」 |
| **剧本库** | `trpg.module-list` / `trpg.module-series` | 列出全部剧本 / 按系列分组 |
| | `trpg.module-get` | 当前群载入的模组 + 进度（动态提示词用） |
| | `trpg.module-section` | 读规则速查 / 某一幕正文 / 模组信息，带长度截断 |
| | `trpg.module-search` | 按关键词搜本地剧本库 |
| | `trpg.module-import` | 把网页正文抓成剧本（按「第一幕 / Act 1」自动切幕） |

**本版未提供**（`trpg-gm` 会自动降级，只提示「面板功能还没装好」）：
`trpg.panel-*`（面板）、`trpg.map-*`（地图）、`trpg.wallet-*` / `trpg.shop-*`（钱包商店）、`trpg.doc-*`（文档收件箱，依赖 `file-inbox`）。

## 剧本库格式

一个文件夹 = 一个剧本，放在 `data/trpg-tools/modules/<id>/`：

```
data/trpg-tools/modules/harbor-night/
    module.json      # 必需：元数据 + 每幕目录
    rules.md         # 可选：规则速查正文
    act-1.md         # 第一幕正文
    act-2.md
```

`module.json` 最小写法：

```json
{
  "id": "harbor-night",
  "name": "港口的夜",
  "series": "我的战役",
  "system": "COC7",
  "summary": "一句话简介（搜索会匹配这里）",
  "acts": [
    { "index": 1, "title": "下船", "file": "act-1.md", "goal": "找到线人", "checks": ["侦查 50"] },
    { "index": 2, "title": "仓库", "file": "act-2.md" }
  ]
}
```

- `acts[].goal` / `checks` / `battle` / `summary` 只是**给 GM 的结构化线索**：填了 GM 就不用读正文（省 token），没填则回退到读正文（截 700 字）
- 正文按需读取，单次上限默认 6000 字（可配），所以一个本可以写很长
- 删掉文件夹 = 从剧本库移除，没有任何数据库

装好后插件会在数据目录生成一份《剧本模板.md》，照着复制即可。

## 上手三步

在群里说：

1. **「开跑团模式」** → 模型调用 `gm_mode(true)`，人设切换成 GM
2. **「载入《XXX》第一幕」** → 绑定模组与进度
3. **「我想建卡，力量 60 敏捷 50 侦查 45」** → 写入人物卡

之后就是正常跑团：「我推开门」「投个侦查」——GM 会自己掷骰、读当前幕、并只告诉你这个角色该知道的事。

## 设计要点（为什么这么做）

- **认知隔离**：`character-get` 这类能力永远只作用在 `(chatKey, userId)` 上，插件不提供「读别人私密卡」的能力，模型就算指名也拿不到。
- **每群独立**：跑团开关、进度、人物卡、情报全部按 `chatKey` 隔离，一个群开团不会污染另一个群。
- **软依赖**：`trpg-gm` 用 `hasCapability` 探测，插件少提供某个能力不会让它崩，只是对应工具回一句提示。
- **情报可信度是算出来的**，不是编的：`certainty = min(1, 重要度/3 × 0.5^(经过小时/半衰期))`，过了半衰期就衰减一半，`certainty ≥ 0.6` 才算「可以当事实说」。

---

## 已知限制

- **不解析 PDF**：剧本要么手写成 Markdown，要么用 `module-import` 抓网页。加密或字体无 ToUnicode 的 PDF 提取是另一个问题，不在本插件范围内。
- **面板 / 地图 / 钱包 / 商店未实现**：这些能力名没写进清单（声明了不实现会被审计拦）。
- **情报没有地图数据**：`intel-known` 只知道「哪些地点不一致」，距离衰减用一个保守系数估，不是真的算距离。
