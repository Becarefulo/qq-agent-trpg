# 跑团指令大全（小鲸鱼 · DnD 5e）

> 全部不用 @，发出去就生效，**不消耗模型额度**。
> 中文句号「。pc」、全角「．pc」都能识别。

---

## 一、开团控制

| 指令 | 作用 |
|---|---|
| `.gm on` | 开跑团模式（模型开始以 GM 身份叙事） |
| `.gm off` | 关跑团模式 |
| `.mod` | 看剧本库里有哪些本 |
| `.mod load 蝗金岛` | 载入某个本（按名字或 id） |

---

## 二、建卡

| 指令 | 作用 |
|---|---|
| `.pc roll` | 随机车卡：4d6 取高 3 掷六属性，随机种族 + 背景 + 职业，技能熟练自动算好，**并发一套初始装备** |
| `.pc roll 名字 张三` | 随机车卡并起名 |
| `.pc 建卡 力量14 敏捷16 体质13 智力11 感知12 魅力9` | 按指定属性建卡 |
| `.pc 侦查45 图书馆50` | 加技能（技能值 = 属性调整值 + 熟练加值） |
| `.pc 名字 张三` | 改名字 |
| `.pc 种族 矮人` | 改种族（9 个 PHB 种族） |
| `.pc 职业 战士` | 改职业（12 个 PHB 职业） |
| `.pc 出身 士兵` | 改背景（13 个 PHB 背景） |
| `.pc 初始装备` | 按职业补发起步装备（每个角色只发一次） |

---

## 三、查卡

| 指令 | 作用 |
|---|---|
| `.pc` | 看自己的人物卡（属性 / 技能 / HP / 护甲 / 盾牌 / AC / 状态 / 等级 / 金币） |
| `.pc 技能` | 列出卡上全部技能（卡面只显示前 12 个） |
| `.pc 物品` | 看背包 |
| `.pc 队伍` | 看队伍卡册 |

---

## 四、装备

| 指令 | 作用 |
|---|---|
| `.pc 装备 长剑` | 装武器（必须在背包里） |
| `.pc 装备 皮甲` | 穿护甲（自动进护甲槽） |
| `.pc 装备 盾牌` | 拿盾牌（AC +2） |
| `.pc 卸下` | 卸武器，回到徒手 1d3 |
| `.pc 卸下 护甲` | 只卸护甲 |
| `.pc 卸下 盾牌` | 只卸盾牌 |
| `.pc 拿 火把` | 往背包里塞一件东西（剧情捡到用） |
| `.pc 丢 火把` | 从背包扔掉一件 |

**AC 算法**：`护甲基础值 + min(敏捷调整值, 护甲敏捷上限) + 盾牌 2 + 魔法加值`；无甲 = `10 + 敏捷`。

## 五、金币 · 商店 · 开箱

| 指令 | 作用 |
|---|---|
| `.pc 金币` | 看余额 |
| `.pc 金币 +120` | 加钱 |
| `.pc 金币 -30` | 花钱 |
| `.pc 金币 100` | 直接设成 100 |
| `.pc 商店` | 看价目表（12 件装备 + 9 种护甲 + 药水等） |
| `.pc 买 治疗药水` | 下单，钱不够会拒绝 |
| `.pc 开箱` | 开宝箱（战斗打死敌人掉 1 个） |

**开箱掉落**：金币 / 杂物 / 药水 / 普通武器 / 好武器 / **魔法武器 +1** / 空箱。

## 七、战斗

| 指令 | 作用 |
|---|---|
| `.战` | 看战况（第几轮、轮到谁、各人 HP/AC） |
| `.战 开` | 开战：自动掷先攻（1d20 + 敏捷）排序 |
| `.战 加 哥布林 hp12 ac13 init15 atk4 dmg1d6+2` | 加敌人（`atk`/`dmg` 可省，默认 +3 / 1d6+1） |
| `.攻击 哥布林 长剑` | 玩家攻击（自动算命中与伤害） |
| `.攻击 哥布林` | 不写武器 = 用装备的那把 |
| `.施法 哥布林 魔能爆` | 法术攻击（自动用最高的施法属性） |
| `.战 打 张三 8` | 手动给某人扣血（GM 用） |
| `.战 下一回合` | 推进到下一个 |
| `.战 敌方回合` | 所有怪自动出手（命中 + 伤害 + 扣玩家 HP），打完自动推进 |
| `.战 结束` | 收场，打死敌人则掉落 1 个宝箱 |
| `.pc 先攻` | 重新投先攻排序 |
| `.pc 下一个` | 先攻表轮到下一个 |

**规则**：

- 命中 = `1d20 + 力量/敏捷调整值 + 熟练加值 + 武器加值` vs 目标 AC
- 伤害 = `武器骰 + 调整值 + 武器加值`，天然 20 **双倍**，天然 1 必失
- 灵巧/远程武器（匕首 / 短剑 / 手弩 / 短弓 / 长弓）取**力量和敏捷里更高的那个**
- **不是你的回合不能行动**（会提示轮到谁）
- 中毒 / 恐惧 / 力竭 / 目盲 / 束缚 → 检定自动劣势

**可用武器**：徒手 1d3、匕首 1d4、短剑 1d6、长剑 1d8、大剑 1d10、战锤 1d8、长枪 1d10、木棒 1d4、手弩 1d6、短弓 1d6、长弓 1d8

**可用法术**（12 个）：魔能爆 1d10、火焰箭 1d10、冷冻射线 1d8、电爪 1d8、毒气喷溅 1d12、圣火 1d8、荆棘鞭 1d6、心灵冲击 1d6、冰霜之刃 1d10、**魔法飞弹 3d4+3（自动命中）**、燃烧之手 3d6、雷鸣波 2d8

## 八、状态 · 休息 · 消耗品

| 指令 | 作用 |
|---|---|
| `.pc 状态` | 看当前状态 |
| `.pc 状态 中毒` | 加状态（中毒 / 倒地 / 恐惧 / 束缚 / 目盲 / 力竭） |
| `.pc 状态 -中毒` | 去掉状态 |
| `.pc 受伤 8` | 扣血（归零自动挂「倒地」） |
| `.pc 治疗 8` | 回血 |
| `.pc 短休` | 短休：回一个生命骰 |
| `.pc 长休` | 长休：血回满 |
| `.pc 法术位 2/4` | 设法术位 |
| `.pc 法术位 -1` | 消耗一个 |
| **`.pc 用 治疗药水`** | 喝药水，回 10 HP（消耗掉） |
| **`.pc 用 解毒剂`** | 解除中毒（消耗掉） |
| **`.pc 用 医疗包`** | 回 5 HP（消耗掉） |

> 火把、绳索这类场景道具**没有自动效果**，用不用得上由 GM 判。

## 九、成长 · 重置

| 指令 | 作用 |
|---|---|
| `.pc 升级` | 里程碑升一级（HP 上限一起涨，不记经验） |
| `.pc 清卡` | 先给警告，不会直接删 |
| `.pc 清卡 确认` | 真的删掉，可重新建卡 |

> 已经是**里程碑制**：不看经验。`.pc 经验 +300` 会提示"现在不记经验"。
