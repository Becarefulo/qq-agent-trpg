# 跑团指令表（可直接发群公告）

【小鲸鱼 · 跑团指令表】

▍开团
.gm on               开跑团模式
.gm off              关跑团模式
.mod                 看剧本库里有什么本
.mod load 蝗金岛      载入某个本（按名字或 id）

▍建卡
.pc roll             随机车卡：4d6 取高 3 掷六属性，随机种族+背景+职业，技能熟练自动算好
.pc roll 名字 张三    随机车卡并起名
.pc 建卡 力量14 敏捷16 体质13 智力11 感知12 魅力9    手写属性
.pc 侦查45 图书馆50    加技能（技能值 = 属性调整值 + 熟练加值）
.pc 名字 张三         改名字
.pc 种族 矮人         改种族
.pc 职业 战士         改职业
.pc 出身 士兵         改背景

▍查卡
.pc                  看自己的人物卡（属性 / 技能 / HP / 状态 / 等级）
.pc 技能              列出全部技能
.pc 队伍              看队伍卡册

▍金币 · 商店 · 地图
.pc 金币             看金币
.pc 金币 +120        加钱
.pc 金币 -30         花钱
.pc 商店             价目表
.pc 买 治疗药水       下单
.pc 地图 / .pc 去 酒馆  看地图 / 移动

▍战斗
.战                  看战况
.战 开               开战（自动掷先攻排序）
.战 加 哥布林 hp12 ac13 init15   加敌人
.攻击 哥布林 长剑     攻击（自动算命中与伤害）
.战 打 张三 8        怪物打玩家
.战 下一回合 / .战 结束

▍跑团中
.pc 状态 中毒         加状态（中毒 / 倒地 / 恐惧 / 束缚 / 目盲 / 力竭）
.pc 状态 -中毒        去掉状态
.pc 状态              看当前状态
.pc 受伤 8 / .pc 治疗 8   扣血 / 回血
.pc 短休 / .pc 长休    休息回血 / 回满
.pc 法术位 2/4        设法术位；.pc 法术位 -1 消耗
.pc 先攻 / .pc 下一个  投先攻排序 / 轮到谁
.pc 物品 / .pc 拿 X / .pc 丢 X   背包
.pc 升级              里程碑升一级（HP 上限一起涨）

▍推倒重来
.pc 清卡              先给警告，不会直接删
.pc 清卡 确认         真的删掉

────────────────────
规则：DnD 5e
· 检定 = 1d20 + 技能值 vs DC，优势/劣势自动处理（中毒等状态会自动带劣势）
· 这些指令不用 @ 小鲸鱼，发出去就生效，也不消耗模型额度
· 中文句号「。pc」一样认
